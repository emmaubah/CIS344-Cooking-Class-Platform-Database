# Cooking Class Platform Database

## Project Overview
This project was developed for CIS 344: Database Design and Programming.
It implements a relational database for a Cooking Class Platform using
MySQL and MySQL Workbench.

## Main Entities
- Student
- Instructor
- Cooking Class
- Class Session
- Enrollment

## Relationships
- Instructor 1:N Cooking Class
- Cooking Class 1:N Class Session
- Student M:N Class Session through Enrollment

## Repository Contents
- Hand-drawn Chen ER diagram
- MySQL Workbench EER diagram
- MySQL Workbench `.mwb` model
- SQL creation and query scripts
- Final project report

## Database Software
MySQL Server
MySQL Workbench
